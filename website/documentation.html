Getting Started

Install the client as described on the download page: Minecraft 1.21.11, Fabric Loader, Fabric API, then the client jar in your mods folder.

Once in a world, the essential keys are:

  • Right Shift — open and close the ClickGUI (default, rebindable)
  • F6 — config profiles manager
  • F7 — friends manager
  • F8 — HUD editor
  • F9 — cloud configs
  • F10 — debug overlay

ClickGUI

The ClickGUI is organized in draggable panels for Combat, Visuals, Movement, Misc and Client Settings. Use the search field to filter modules by name. Panel positions, GUI scale and the GUI keybind are saved automatically.

Setting types

  • Toggle — click a module to enable or disable it.
  • Slider — click and drag to set a numeric value.
  • Range — two handles define a minimum and maximum (used for the randomized combat delays). The minimum can never cross the maximum.
  • Mode — a dropdown with the available options.
  • Color — a color picker with alpha for theme colors.
  • Keybind — click the row, press a key (or a mouse button), press Esc to cancel recording, or use Clear to unbind.
  • Action — a button that triggers something (e.g. reset functions in Client Settings).

Settings with a description show it as a tooltip on hover. Every control writes directly into the client's real configuration — nothing is cosmetic.

Modules

MaceSwitch (Combat)

The core module. When enabled, it detects a player roughly three blocks below you (configurable height and tolerance) within your configured reach, then runs a non-blocking sequence: equip chestplate → switch to mace → attack. All three delays are randomized inside configurable ranges, the target is re-validated right before the attack, and the sequence aborts safely if the world, your state or the target changes.

Sprint (Movement)

Sprint helper with Legit/Rage modes, omnidirectional sprinting, keep-sprint and a forward-requirement option.

Note: ESP, Fullbright, HUD, Speed, Step, AutoGG and NoRotate are currently placeholders without active behavior and expose no settings.

HUD

The HUD shows the watermark, FPS, coordinates, speed and active modules. Open the editor with F8 to move, scale, recolor, rename, show or hide each element — or reset an element to its default. Your layout persists across restarts.

Keybinds

By default only the GUI has a keybind (Right Shift); every module starts unbound. Click a module's keybind row in the ClickGUI to record a key or mouse button. If the key is already used by another module you'll get a warning notification. The GUI keybind can be changed but never cleared to nothing, so you can't lock yourself out.

Config & Profiles

All settings live in .minecraft/config/aerialmace.json (client/combat state) and .minecraft/config/aerialmace-gui.json (GUI, HUD, friends, keybinds). Configs are saved with a short delay after changes — not on every tick — and rotating backups (.bak files) are kept so a corrupted file can't destroy your setup.

Profiles (F6) store complete config snapshots: create, save, load, rename (press R and type a name) or delete them. A corrupt profile is skipped safely instead of breaking the client.

Cloud Configs

Press F9 to open cloud configs. Upload your current client config under a name, or browse and download configs shared by other players. Uploaded configs contain gameplay settings only — cloud connection details are never included. The public server rate-limits uploads per author and automatically prunes old entries; no account is needed.

Friends

Manage friends with F7: add by name, remove, list. With Ignore Friends enabled in the combat settings, friends are never selected as targets by the MaceSwitch module.

Themes

In Client Settings you can change the accent, background, panel, module-active, text, secondary-text, border and hover colors with a live color picker. Everything in the GUI and HUD follows your theme instantly and persists.

Troubleshooting

  • Config looks wrong after a crash — delete the affected file in .minecraft/config/; the client regenerates defaults, and a .bak backup may still hold your settings.
  • A setting seems stuck — use "Reset Module Settings" or "Reset Everything" in Client Settings. "Reset Everything" asks for a confirmation click first.
  • Check your setup — the debug overlay (F10) shows config dirty state, versions and the combat state machine phase.

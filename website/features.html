Features

What's inside

Every feature below exists in the client today — no roadmaps, no placeholders.

⚔️

MaceSwitch (Combat)

The core module: a non-blocking state machine that equips your held item as chestplate, hotbar-switches to a mace and attacks a detected player roughly three blocks below you. All delays are randomized ranges you can tune in the GUI, targets are re-validated before every strike, and friends can be excluded.

🏃

Sprint (Movement)

Sprint helper with Legit and Rage modes, omnidirectional sprinting, keep-sprint after hits and a forward-requirement option.

🖱️

ClickGUI

Animated panels (Combat, Visuals, Movement, Misc, Client Settings), live search, two-handle range sliders, sliders, toggles, mode dropdowns, a color picker with alpha, keybind capture and tooltips on every described setting.

📊

HUD & HUD Editor

Watermark, FPS, coordinates, speed and active modules. The editor (F8) moves, scales, recolors and renames each element; layouts persist across restarts.

🎨

Theme System

Accent, background, panel, module-active, text, secondary text, border and hover colors — all configurable in-game with a live color picker. No hardcoded colors anywhere in the GUI.

💾

Profiles & Config System

Create, save, load, rename and delete profiles (F6). Configs are versioned, written with a dirty-state delay instead of per-tick disk IO, and protected by rotating backups.

☁️

Cloud Configs

Share client configs with other players (F9): upload under a name, browse and download. The server rate-limits uploads per author and keeps only the newest 500 configs — free to run, hard to abuse.

👥

Friends

Central friend manager (F7) with add/remove and nick resolution. The combat module's "Ignore Friends" setting guarantees friends are never selected as targets.

🔔

Notifications

Animated, FPS-independent toasts (INFO / SUCCESS / WARNING / ERROR) for module toggles, profile actions, cloud results, config problems and keybind conflicts.

⌨️

Keybinds

The GUI opens with Right Shift by default; every module starts unbound. Keys and mouse buttons are assignable per module, conflicts are flagged and warned.

🔍

Debug Overlay

F10 shows FPS, current screen, GUI scale, config dirty state, the combat state machine phase, active modules and the real client/Minecraft/Fabric versions.

🧱

Built to Last

Robust error handling (a corrupt config can't crash the client), a typed event bus, central logging and a 52-test unit suite backing settings, ranges and the combat config.

Honest note: ESP, Fullbright, HUD, Speed, Step, AutoGG and NoRotate currently exist as module entries without active behavior, so they expose no settings. The features listed above are the ones that fully work today.

See it in game

Grab the latest jar and open the ClickGUI with Right Shift.

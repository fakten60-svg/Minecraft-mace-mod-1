Frequently asked questions

Which Minecraft versions are supported?

Gugugaga Client is built for Minecraft Java Edition 1.21.11 with Fabric (Loader 0.19.5+, Fabric API 0.141.6+1.21.11, Java 21). Other versions are not tested.

How do I install the client?

Install Minecraft 1.21.11 and Fabric Loader, then put Fabric API and the client jar into your mods folder. Start the game with the Fabric profile. Details: download page.

How do I open the ClickGUI?

Press Right Shift in game. You can rebind the GUI key in Client Settings — it can be changed but never cleared, so the GUI is always reachable.

Where are configurations stored?

In .minecraft/config/: aerialmace.json holds the client/combat state, aerialmace-gui.json holds GUI, HUD, friends and keybinds. Profiles are stored in the aerialmace-profiles folder. Rotating .bak backups protect all of them.

How do I change keybinds?

Open the ClickGUI, click a module's keybind row, then press a key or mouse button. Esc cancels recording, Clear unbinds. If the key is already bound to another module you get a warning notification.

How do I reset settings?

Client Settings offers Reset Module Settings, Reset Keybinds, Reset GUI Layout (also resets HUD positions) and Reset Everything — the latter requires a confirmation click and keeps your friend list.

What are cloud configs?

Press F9 to upload your client config or download configs shared by other players. No account needed. Uploads are rate-limited and old entries are pruned automatically; gameplay settings only are shared — never your cloud connection details.

How does the MaceSwitch module decide when to run?

It only runs when you are alive, in a world, and a player is detected roughly three blocks below you (configurable height and tolerance) within your configured reach. The sequence then runs as a non-blocking state machine and aborts safely if any condition stops holding. With Ignore Friends enabled, friends are never targeted.

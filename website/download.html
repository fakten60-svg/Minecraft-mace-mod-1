Install Minecraft 1.21.11

Use the official Minecraft launcher and make sure the 1.21.11 Java Edition version is installed.

Install Fabric Loader

Run the Fabric installer for 1.21.11 and select the Fabric profile afterwards in the launcher.

Add Fabric API

Download Fabric API (0.141.6+1.21.11 or compatible) and put it into your mods folder — the client depends on it.

Add the client

Download gugugaga-client-1.2.0.jar above and drop it into the same mods folder (.minecraft/mods).

Start the game

Launch Minecraft 1.21.11 with the Fabric profile. In game, press Right Shift to open the ClickGUI.

Older releases (v1.1.0, v1.0.0) are available on the GitHub releases page. Their jar files use the older aerial-mace-automation file name but contain the same mod.
